Вариант 7. Викторина по Казахстану

Описание
Игра похожая по приципу кто хочет стать миллионером тебе задают впорсо а к нему 3 ответа и только один верный. 
В нашем случае 5 вопросов и за каждый верный ответ дают одно очко, для победы нужно набрать как минимум 5.

Как запустить
1. Установить Python.
2. Открыть папку с проектом.
3. Выполнить в терминале: python game.py

Меню
Главное меню: есть базовый выход из игры - 0, правила - 2, и конечно сама игра - 1.

Проверки
| № | Что делал | Что ожидал | Что получилось |
|---|-----------|------------|----------------|
| 1 | Ответил верно на все 5 вопросов | 5 из 5, победа | Победа, вывод результата 5 из 5 |
| 2 | Ответил неверно на 2 и больше вопросов | Поражение | Поражение, вывод результата 3 из 5 |
| 3 | Ввёл 7 или букву вместо ответа | Неверный ввод, вопрос повторяется | Вывод неверный ввод, вопрос повтаряется |
| 4 | Сыграл, вернулся в меню, сыграл снова | Счёт начался с 0 | Счёт сбрасывается до исходного полажения |
